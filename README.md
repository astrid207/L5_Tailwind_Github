Java Nook – Coffee Shop Website

About the Project

Java Nook is a simple coffee shop website created using HTML and Tailwind CSS. The website introduces the coffee shop, its story, and its welcoming atmosphere.

Features

Navigation Bar: Links to different sections of the website, including Home, About, Menu, and Contact.

Hero Section: Displays the coffee shop name and tagline, "Every sip tells a story", over a background image.

About Us Section: Introduces Java Nook's history, values, and philosophy of quality over quantity.
